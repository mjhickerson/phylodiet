# Source chronograms

`graft_tree.py` reads the published source trees from the directory named by `PHYLOPLATE_SOURCES` (default `sources/`), under the file names used in `scripts/backbone.py`, where each source is cited and its download location noted. Most are large public downloads and are not kept in the repository.

`kim2026_red.nwk` is the exception: the posterior-mean tree of the correlated-clock MCMCtree analysis from Kim et al. (2026, preprint; Ahnfeltia genomes and a nuclear-BUSCO timetree of the red algae, Fig. 2E), provided by Hocheol Kim on 2026-09-28 with permission to use it in Phyloplate and to redistribute it here with citation. Tip labels have had their numeric prefixes removed and branch lengths have been converted from the analysis's 100-Myr units to Myr; nothing else was changed. Please cite the paper if you reuse it.
